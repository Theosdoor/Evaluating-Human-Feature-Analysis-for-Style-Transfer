# ACV Coursework — Paper

NeurIPS 2025 format (`neurips_2025.sty`, preprint mode). Output PDF: `paper/build/main.pdf`.

## Structure

```
paper/
  main.tex                        # top-level document
  ref.bib                         # bibliography
  neurips_2025.sty                # style file (do not modify)
  sections/
    intro.tex                     # introduction
    human_feature_analysis.tex    # human feature analysis section
    real_world_application.tex    # real-world application section
  figs/                           # figures (PDF/PNG preferred)
  build/                          # latexmk output (git-ignored)
```

The conclusion is written inline in `main.tex` (no separate section file).

## Build

```bash
make -C paper          # build PDF → paper/build/main.pdf
make -C paper clean    # wipe build artefacts
```

Always run the build after editing any `.tex` file to check for errors. LaTeX Workshop is configured to use `make` and output to `paper/build/`.

| 2.2 | Local/temporal enhancement + video submission | 30% | 250 |
| 3 | Report quality | 10% | — |

Examiners **stop reading at the word limit** — stay under it.

### Word count: included vs excluded

**Included:** all prose, in-text citations, footnotes.  
**Excluded:** diagrams, tables, equations, abstract, bibliography, appendices. Do not use tables/figures merely to dodge the word count — the examiner will include those words.

## Writing Guidelines

- Each answer needs enough detail (maths, result analysis, visualisations, references) to demonstrate understanding.
- Use figures and tables to show results; reference every figure in the text.
- Cite all external code, models, and datasets in both the report and the notebook comments.
- Be explicit about hardware used and training time — marks are not awarded for raw compute.

## Submission

- Submit the compiled PDF alongside the code ZIP.
- Do **not** commit `paper/build/` — it is regenerated by `make`.
- Figures go in `paper/figs/`; reference them with relative paths (e.g. `figs/my_fig.pdf`).
